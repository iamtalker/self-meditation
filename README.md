# 셀프 메디테이션 (Self Meditation)

개인용 안드로이드 명상 앱입니다. 일정한 박자 소리에 주의를 묶어 집중 상태로 들어가고, 이후 박자가 서서히 줄어들면서 그 상태를 스스로 이어 가는 단전호흡형 명상을 돕습니다.

> 상태: **프로토타입 (v0.2.3)** — 에뮬레이터와 실제 폰에서 설치·앱 내 업데이트까지 확인했습니다. 소리 다듬기와 장시간 재생 검증이 남아 있습니다.

---

## 만든 이유와 방향

명상을 크게 세 가지로 합니다: 완전한 침묵, 한 점 집중(단전호흡), 상상 훈련.

- **완전한 침묵**: 앱이 필요 없습니다.
- **한 점 집중**: 이 앱이 다루는 부분입니다. 목소리 없이 박자만 씁니다.
- **상상 훈련**: 주제가 매번 달라서 그때그때 대본과 음성을 만들어야 합니다. 아직 앱에 없습니다.

단전호흡은 두 단계로 나눠 봅니다.

1. **유도**: 규칙적인 박자에 집중해서 잡생각을 끊고 집중 상태로 들어갑니다.
2. **유지**: 박자에 덜 의존하면서 그 상태를 스스로 이어 갑니다.

---

## 현재 되는 것

한 번의 세션은 이렇게 흘러갑니다.

1. 시작할 때 징이 한 번 울립니다.
2. 4초 뒤부터 박자가 시작됩니다.
3. **유도 단계**: 박자가 같은 크기로 또렷하게 이어집니다.
4. **유지 단계**: 설정에 따라 박자가 90초에 걸쳐 줄어듭니다.
5. 마지막에 징이 한 번 울리고 자동으로 끝납니다.

### 설정 항목 (모두 저장됨)

| 항목 | 내용 |
|---|---|
| 소리 종류 | 징, 벨, 목탁, 북, 저음 |
| 음높이 | -18 ~ +12 반음 |
| 울림 길이 | 0.5배 ~ 2.0배 |
| 소리 미리듣기 | 고른 소리를 한 번 들어 봄 |
| 박자 간격 | 0.5초 ~ 10초 (0.5초 단위), 기본 2초 |
| 유도 시간 | 분 단위 입력, 기본 5분 |
| 유지 시간 | 분 단위 입력, 기본 15분 |
| 유지 단계의 박자 | 없음 / 약하게 / 그대로 |

**유지 단계의 박자**

- **없음**: 90초에 걸쳐 사라지고 이후 무음
- **약하게**: 90초에 걸쳐 볼륨이 15%까지 줄고 간격이 2배로 벌어짐
- **그대로**: 끝까지 같은 크기

모든 소리는 앱이 직접 합성합니다(녹음 파일을 쓰지 않음). 재생은 포그라운드 서비스로 실행되어 화면을 꺼도 이어지도록 만들었습니다.

## 알려진 문제 / 아직 안 된 것

- **소리 품질**: 전부 합성음이라 실제 악기보다 단조롭습니다. 폰에서 들어 보며 다듬는 중입니다.
- **낮은 소리**: 폰 스피커는 약 100Hz 아래를 거의 재생하지 못합니다. 그래서 80Hz 아래 성분은 한 옥타브 올려 접어 넣습니다(저음의 실제 중심은 약 150Hz). 더 깊은 소리는 이어폰이나 헤드폰이 필요하며, 접지 않는 모드는 아직 없습니다.
- **화면 끈 장시간 재생**: 에뮬레이터에서만 확인했습니다. 실제 폰에서 20분 이상 끊기지 않는지, 배터리 최적화 영향은 아직 모릅니다.
- **화면 두드리기 기능 없음**: 박자에 맞춰 화면을 두드리는 기능은 넣지 않았습니다.
- **상상 훈련 모드 없음**: 아래 "다음 단계" 참고.
- **디버그 빌드만 있음**: 배포용 서명 빌드는 없습니다(개인용 설치에는 디버그 APK로 충분).
- `android-app/app/src/main/res/raw/meditation_sample.wav`는 예전 버전의 흔적으로 현재 코드에서 쓰지 않습니다.

## 폴더 구성

| 경로 | 설명 |
|---|---|
| `android-app/` | 안드로이드 앱 소스 (Java, Gradle) |
| `sample/` | 빌드된 APK와 음원 샘플 (git에는 올리지 않음) |

주요 소스는 `android-app/app/src/main/java/com/selfmeditation/app/` 아래에 있습니다.

| 파일 | 역할 |
|---|---|
| `SoundSynth.java` | 징·벨·목탁·북·저음을 수식으로 합성 |
| `PlaybackService.java` | 세션 진행(박자 스케줄, 유도→유지 전환, 시작·끝 징), 포그라운드 서비스 |
| `MainActivity.java` | 설정 화면, 미리듣기, 남은 시간 표시, 업데이트 표시 |

| `Versions.java` | 버전 번호 비교 |
| `UpdateReceiver.java`, `ReplacedReceiver.java` | 설치 결과 처리, 업데이트 후 알림 |

## 설치 방법 (안드로이드 폰)

필요: 안드로이드 8.0(API 26) 이상.

1. 빌드한 `SelfMeditation-debug.apk`를 폰으로 옮깁니다(USB, 드라이브 등).
2. 파일을 눌러 설치합니다. "알 수 없는 앱 설치"를 묻으면 허용합니다.
3. 앱을 열고 알림 권한을 허용합니다(재생 중 알림 표시용).
4. 소리와 시간을 정하고 **시작**을 누릅니다.

## 앱 업데이트

앱 안에서 GitHub 최신 릴리즈를 받아 설치합니다.

- 실행할 때 6시간에 한 번 자동으로 새 버전을 확인하고, 있으면 화면 위쪽에 배너가 뜹니다. 배너를 누르면 설치가 시작됩니다.
- 화면 아래 **업데이트 확인**을 누르면 새 버전이 있을 때 바로 내려받아 설치를 시작합니다.
- 마지막 "설치" 확인은 안드로이드 규칙상 직접 눌러야 합니다. 처음에는 "이 출처 허용"도 켜야 합니다.
- 릴리즈 태그(`v0.2.3` 등)가 버전이고, 첫 번째 `.apk` 파일을 받습니다. 저장소가 **공개**여야 동작합니다.
- 같은 서명 키로 빌드한 APK여야 덮어써지고, `versionCode`는 올라가야 합니다(낮추면 거부됨). 그래서 이 PC에서 빌드한 APK만 업데이트로 설치됩니다.

## 빌드 방법 (개발자용)

- 필요한 것: Android SDK, JDK 17 이상, Gradle 8.11.1
- **경로에 한글이 있으면 빌드가 실패합니다.** 이 프로젝트는 `1. 개발중` 폴더 때문에 영문 경로(예: `C:\build\selfmeditation`)에 복사해서 빌드합니다.
- 이 저장소에는 Gradle wrapper가 포함되어 있지 않습니다. 영문 경로 빌드 폴더의 wrapper를 사용합니다.

```bash
cd /c/build/selfmeditation
./gradlew.bat assembleDebug
```

결과물: `app/build/outputs/apk/debug/app-debug.apk`

에뮬레이터에서 확인:

```bash
adb install -r "sample/SelfMeditation-debug.apk"
adb shell monkey -p com.selfmeditation.app -c android.intent.category.LAUNCHER 1
```

## 다음 단계 (제안)

1. **실기기 테스트**: 화면을 끈 채 20분 이상 재생되는지, 소리가 어떻게 들리는지 확인
2. **소리 다듬기**: 폰에서 들은 느낌에 맞춰 징·벨·저음의 음색 조정
3. **내 기본값 저장**: 몰입이 잘 오는 소리·박자 조합을 찾으면 기본값으로 고정
4. **상상 훈련 모드**: 주제를 정하면 대본과 음성을 만들어 PC에서 파일로 옮기고, 앱은 목록에서 골라 재생하는 방식으로 시작. 음성은 자연스러운 TTS를 비교해 정함
5. **빌드 정리**: Gradle wrapper를 저장소에 포함하고 영문 경로 복사 없이 빌드되도록 정리

## 메모

- 이 앱은 의학적 치료 도구가 아닙니다. 불안이나 수면 문제가 심하면 전문가와 상담하세요.
- 규칙적인 박자나 반복 동작에 집중하면 몰입이 깊어질 수 있다는 것은 널리 알려져 있지만, 소리의 종류나 박자별 효과에 대한 연구 근거는 제한적입니다. 개인차가 크므로 직접 써 보며 맞는 설정을 찾는 용도로 만들었습니다.
